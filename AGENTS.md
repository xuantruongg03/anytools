
# Instructions for Codex

## Workflow
- Inspect only files relevant to the requested task.
- Do not scan the entire repository unless necessary.
- Start by identifying the likely files and dependencies.
- Ask before making unrelated changes.
- Keep changes minimal and focused.
- Do not rewrite working code without a clear reason.

## Testing
- Run only relevant tests first.
- Do not run the full test suite unless necessary.
- Report tests that were run and their results.
- Do not claim tests passed if they were not run.

## Output
- Summarize changed files and key changes briefly.
- Explain any unresolved issues.
- Avoid repeating large sections of source code.
